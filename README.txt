ANTELMO — instalación rápida

1. Descomprime la carpeta.
2. Para probarla en un ordenador, abre index.html.
3. Para instalarla en iPhone como app, los archivos deben estar publicados en una web HTTPS.
4. Una vez publicada:
   - Abre la dirección en Safari.
   - Pulsa Compartir.
   - Pulsa “Añadir a pantalla de inicio”.

Los datos se guardan localmente en el dispositivo.
En Módulos → Datos → Seguridad y copia puedes crear o restaurar una copia JSON completa.
